    Checkoff Question 1: When n = 10000, the stride is 40000 bytes, spanning 10 memory pages. At this point, not only is every access a cache miss, but the TLB (Translation Lookaside Buffer) also starts missing frequently—and a TLB miss is more expensive than a cache miss. That’s why the curve rises superlinearly.
    Checkoff Question 2: The cache transfer unit is a block (typically 64 bytes = 16 ints). Each column within a sub-block contains only blocksize contiguous elements; when blocksize is too small, the fetched cache block is not fully utilized before moving on to the next column. In the four-level loop, the smaller the block size, the more frequently the two outer loops jump between blocks.
